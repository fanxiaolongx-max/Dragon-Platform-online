下拉已内置业务库 netcare 全量 441 张表：有数据的靠前，空表置灰排在最后（可查但无数据）；彩色标签 = 所属模块 / 数据类别，灰色备注 = 同事标注的中文名（可输入中文搜索）。 输索引目录里的源表名也能命中对应落地表，任意表名可直接输入回车。 「只显示这些列」点开为多选：列名搜索 / 全选 / 反选 / 清空，选择按表自动记忆到本地浏览器。 过滤条件可加多条（AND）：列名 + 运算符 + 值；运算符 = != > < >= <= like not like in（like 值可带 %，in 用逗号分隔多值）。查询成功后可在「本模块其他落地表」切换器中换表重查—— 切换时会先用新表的真实字段校验过滤条件：新表没有的列对应的条件会自动置灰、不随查询下发（其他条件与列选择保留）。

Dragon Claw 助理 常驻右侧 · 对话查数 · 经确认后修改应用数据
自然语言查数直接提问，Dragon Claw 自动查表结构、写只读 SQL、汇总结论并注明口径。
写入先确认新增 / 修改 / 删除应用表前展示变更预览，你点确认后才执行，并记录审计日志。
能力由后端开放工具清单来自 /api/agent/capabilities，业务库只读、SQL 守卫在服务端强制。
首次提问会经浮窗内嵌的原 ADC 聊天页自动建立会话，之后直连对话接口；助理栏切换菜单不刷新，可拖动、调大小，Esc 收起。 只有部署到数字人云端（与 ADC 同源）后才能真实对话，本地仅预览界面。
